# Beast of Reincarnation Wiki

Independent, source-tracked fan wiki for **Beast of Reincarnation** — Game Freak's brand-new one-person, one-dog action RPG (published by Fictions, releasing **4 August 2026**).

🔗 **Live site: https://beastreincarnationwiki.com**

Community guides, boss walkthroughs, combat mechanics, and build tips for Emma and Koo's journey. Every fact carries a visible confirmation status and links back to its source (official Steam page, App 2001760); nothing is fabricated.

## Tech stack

- [Astro](https://astro.build/) — static output
- [Tailwind CSS](https://tailwindcss.com/)
- `@astrojs/sitemap` — automatic sitemap generation
- Deployed on Cloudflare (Workers Static Assets)

## Commands

| Command | Action |
| --- | --- |
| `npm install` | Install dependencies |
| `npm run dev` | Start the dev server at `localhost:4321` |
| `npm run build` | Build the production site to `./dist/` |
| `npm run preview` | Preview the build locally |
