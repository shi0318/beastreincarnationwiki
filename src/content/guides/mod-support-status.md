## Official support versus community projects

Steam has a `/workshop/` community URL for the app, but the current page surfaces shared screenshots and artwork. A page existing at that address is not evidence that the game supports installable Workshop mods. The Steam store feature listing is the relevant first-party source for whether Workshop support is declared, and it does not list it at this check.

Community projects are separate from official support. The developer's [v1.0.7 patch notes](/guides/patch-notes/) describe official game changes and planned work; they do not announce mod support, endorse third-party files, or guarantee compatibility after future updates.

## A community ultrawide project we can identify

One project has a direct author trail: Steam user `Rake_v2` posted an **"I'm working on ultrawide support"** discussion and linked the GitHub organisation [`therake620-collab`](https://github.com/therake620-collab/Beast-of-reincarnation-Ultrawide-fix-/releases). The repository describes itself as a camera-distance, FOV, and ultrawide fix.

There is an important version boundary. The author's Steam post says **v1.3.1** was available on **August 4, 2026**, while the accessible GitHub release page lists a release tagged **1.3** from **August 3, 2026**. This page therefore does not call either one the universal current version, does not reproduce installation instructions, and does not claim that it works on every display or game patch.

The same Steam post links a Nexus Mods listing. Nexus currently blocks direct automated inspection of its item details, so this guide does not turn the listing into a vetted download recommendation or copy unverified claims from it.

## Use an evidence-first safety boundary

Before considering a third-party file, keep the following limits in mind:

1. Check the project author's release notes, the exact game version, and any removal instructions from the project itself.
2. Back up saves and configuration files before changing anything. A mod may not survive a game update or may conflict with a previous configuration workaround.
3. Do not treat a community tool as a replacement for an official bug fix. For example, v1.0.7 explicitly fixed the upscaling-settings reset; see the [PC performance and settings guide](/guides/pc-performance-settings-fixes/) for the current distinction between official fixes and player reports.
4. Avoid pages that do not identify an author, version, intended change, or reversal path. This site will not publish a bulk "best mods" list without those basics.
