PC patch **v1.1.01** fixed a specific miss. The **Explosive Arrow** manual obtained from a Keeper Golem can now be obtained in **New Game Plus**. Before that note, a Golem drop that failed to appear on a second run stayed failed. After it, the Mountain Route is still the place the manual lives. New Game Plus is the recovery file, not a mailbox that sends the arrows to the Capital.

Beast of Reincarnation has been out since **August 4, 2026**. On **October 20, 2026** it was **$59.99** with no discount, Mixed at **3,780** of **6,399** reviews, with **46** achievements. The manual is a small item inside that larger argument about length. It matters if Erymanth is the fight you are building for, because Explosive Arrows are the tool named for that weakness.

## Where the manual sits

Fuji Frontier Zone is chapter 6, Necrosis, on the Mountain Route after the Great Wall Terraces. That zone holds 9 campsites, 5 shrines, 4 Keeper Golems, the Shark Cutter, and the Explosive Arrow manual. Hastening to the Capital bypasses Fuji Frontier along with Pilgrim's Zone and Matsukawa Colony Zone. A bypass does not move the Golem into the Capital. It leaves the manual in the zone you did not walk.

The v1.1.01 note is narrow. It says the manual from a Keeper Golem can be obtained in New Game Plus. It does not say a New Game file that hastened can open a chest in a zone it skipped. If the only file you have hastened, the recovery is a New Game Plus run that takes the Mountain Route, not a reload of the skipped save.

## When to go back for it

Go back if Erymanth is still ahead and you do not have the arrows. Erymanth is the Capital fight at about level 47. Explosive is the weakness that fight is known for. Walking into it without the manual because you skipped four Keeper Golems is a build choice, not a patch bug.

Go back on New Game Plus if the first file already has the zone achievements and you only missed this one drop. That is the case the patch was written for. The Golem can give the manual on the second run. You still have to reach the Golem. New Game Plus does not autocomplete Fuji Frontier.

Do not go back if you hastened on purpose and you do not care about the arrows or the zone achievements. The skip was the story tool. The manual is optional for a story run that has already decided the Capital is the point. Do not pretend a later patch will mail the item. v1.1.01 said the major update cycle was closing, with the next patch planned as the last in that phase.

## How to pick it up without burning the file

1. Confirm the PC build is v1.1.01 or newer. The Golem fix is in that note. A launch install will not have it.
2. If this is a New Game file and Fuji Frontier is still unchecked, take the Mountain Route. Do not hasten and hope.
3. Find a Keeper Golem in Fuji Frontier. There are four in that zone. The note names the manual as a Golem drop, not as a shrine reward.
4. If the manual did not appear on an older second run, run New Game Plus on v1.1.01 and take the Mountain Route again. The fix is "can be obtained," not "is now in your inventory."
5. Pair it with the Shark Cutter if you are already in the zone. Leaving the crit weapon on the ground to save five minutes is the same mistake as leaving the manual.

Pilgrim's Zone and Matsukawa are the other two skips. They hold Taurus, the Sunrise Sword, Hazebringer, and the Resonance Sword. The Explosive Arrow fix does not collect those. A New Game Plus Mountain Route that only beelines the Golem can still miss the swords. Clear the zone you came back for, or accept the miss.

**ACH_BEAST_OF_REINCARNATION** was at **27.2%** on October 20. **ACH_KENGO** was at **10.9%**. The arrow manual is not those pops. It is a tool for a fight most owners never reach. If you are in the quarter of players still going, the Golem is worth the detour. If you are testing the game on Family Sharing for an hour, you do not need it yet.
