If you are about to begin a second playthrough, troubleshoot a crash, or install a community fix, take a moment to protect your **Beast of Reincarnation save** first. The Steam listing includes Steam Cloud, which is useful when moving between PCs, but cloud synchronization is not the same thing as a manual backup or a promise that every damaged local file can be repaired. A careful copy gives you a fallback before a risky experiment; it does not replace the game's own save system.

This guide is a safety routine, not a claim about an unpublished save-file location or a guaranteed recovery tool. The public store listing confirms Steam Cloud and single-player support. The checked-in patch record also documents a specific save-data degradation issue in an older build, so version checking matters. Keep the game's current patch notes beside this page, and use the exact menu text your platform displays.

## First identify the risk you are dealing with

These situations are easy to confuse, but they need different responses:

- **A missing cloud save:** Steam may be showing a synchronization conflict, or another device may have a newer copy.
- **A game crash:** the application closes, but the save may still load normally afterward.
- **A progression problem:** the save loads, but a quest, achievement, travel action, or character state behaves incorrectly.
- **Persistent save degradation:** a documented older-build fault could affect future save performance after a triggering event.
- **A new-playthrough decision:** New Game Plus or a chapter transition may change what you can access even when the file is healthy.

Do not delete files or repeatedly launch the game until you know which category applies. If Steam reports two different timestamps, stop and compare them before selecting either version. Choosing the wrong side of a cloud conflict can replace the copy you meant to preserve.

## Make a safe manual backup on PC

Steam Cloud is a helpful synchronization feature, but a dated copy outside the game's active save folder gives you a clear rollback point. The precise save directory can vary by platform, account, and installation, and the checked official information does not publish a verified path for every configuration. Avoid copying a path from a random forum post without checking that the files belong to this game and this account.

1. **Close the game normally.** Wait for the application to exit and for Steam to finish any visible cloud synchronization. Do not copy a file while it is changing.
2. **Record the build and time.** Note the game version displayed by your launcher or in-game menu, the platform, and the date. A folder name such as `Beast-of-Reincarnation-before-NG+-2026-10-28` is more useful than `backup-final`.
3. **Locate the active save using the platform you own.** Use the game's Steam community support information or Steam's user-data view when available. Confirm the application/account context before copying anything.
4. **Copy, do not move.** Place the save data in a separate dated folder outside the live game directory. Do not rename files inside the active save folder.
5. **Keep the original intact.** A backup only helps if the original is not overwritten by the experiment you are trying to test.
6. **Make a second copy for a high-stakes transition.** Store it on another drive or a trusted protected location. Do not rely on two folders on the same failing disk as independent backups.

If you are on PlayStation or Xbox, do not apply PC file instructions. Use the console's own save-management and cloud-save interface, and read its overwrite prompts carefully. The Steam Cloud badge says nothing about cross-save between Steam, PlayStation 5, and Xbox Series X|S.

## Check Steam Cloud without creating a conflict

Steam Cloud can carry a save to another PC when the same account launches the game, but it can also prompt you to choose between local and cloud copies after an interrupted session. Before clicking either choice, compare the timestamps and consider which device you used most recently. If you cannot establish which copy contains the latest progress, cancel the launch or leave the conflict dialog open while you investigate; do not guess.

After a clean launch, wait for synchronization to complete before shutting down or opening the game on a second machine. A cloud icon or feature badge does not promise that offline progress will merge automatically. If you played offline on one PC, reconnect that device first and inspect its local save before allowing a different machine's copy to replace it.

Family Sharing also does not create separate simultaneous versions of one save for two people. Treat the save as belonging to the account that is playing. If another person uses the shared library, agree on whose account and device will hold the active run before either person starts a long session.

## The older save-data issue and how to respond

The checked patch notes for **v1.0.10** describe a problem where acquiring certain achievements after fast travel could leave a player beneath the terrain on respawn and **persistently degrade save-data performance thereafter**. That is a specific historical bug description, not evidence that every current save is unsafe or that the same trigger remains present in a later build.

The practical response is to update the game before reproducing an old report, keep a dated backup before testing a travel-and-achievement sequence, and record exactly what happened if the fault repeats. Note the installed version, platform, fast-travel destination, achievement event, and whether the issue survives a full restart. That information helps separate an old known issue from a new crash, a temporary loading problem, or a different save problem.

Do not deliberately repeat a trigger described as degrading save data on your only copy. Do not assume that reinstalling the game restores a healthy save; the local or cloud save may be stored separately from the installed game files. For a current crash, begin with the [crash and performance guide](/guides/beast-of-reincarnation-crashes/) and its current patch-status table.

## Back up before New Game Plus or a major story step

The existing [New Game Plus guide](/guides/new-game-plus-guide/) separates an official feature list from a player-maintained outline of carry-over behavior. Because the source itself is marked as a work in progress, keep your save before choosing a second run. Record the completion state you care about: achievements, collectibles, weapons, seedlings, and any open region checklist. A backup cannot reverse an in-game choice if the game intentionally saves over the same slot, but it gives you a reference copy before you test what the current version does.

Before a major transition, use this short checklist:

- Update to the current stable game build and read the matching notes.
- Finish any optional task you personally want to complete before the transition.
- Confirm Steam Cloud has synchronized, if you are playing on Steam.
- Create a separate dated backup and verify that it contains files and a plausible recent timestamp.
- Avoid changing graphics mods, save tools, and controller configuration during the same session.
- After the transition, load the new state and verify that the game continues normally before removing any older copy.

The [achievement guide](/guides/achievements-guide/) lists the published objectives and clearly marks hidden conditions. It is a useful checklist for planning, but a Steam achievement percentage is not a save-backup system.

## If a save appears missing or will not load

Start with reversible checks. Confirm you launched the correct Steam account or console profile, check whether the game is fully updated, and inspect the platform's cloud status. Restart the launcher only after any conflict prompt has been recorded or resolved deliberately. If the game offers multiple slots, inspect each slot without overwriting one to test another.

If you have a backup, make a copy of the backup before attempting a restore so that you preserve both the original backup and your current state. Restore only through the platform's supported process when possible. Do not download a stranger's save and place it over your own profile; it may belong to another patch, platform, or progression state.

For a support report, include the platform, game version, approximate last successful save time, what happened immediately before the problem, and whether a cloud synchronization prompt appeared. Remove account identifiers and private information from any screenshot you share publicly. Keep the original files untouched until the support process is complete.

## What this guide can and cannot promise

Steam confirms that its version has Steam Cloud, but it does not publish a universal save path, a guarantee against corruption, a detailed conflict-resolution policy for this game, or cross-platform transfer. The v1.0.10 notes confirm a specific past degradation issue, but a patch note is not proof that every later build has the same behavior. The safe recommendation is therefore simple: keep one untouched copy before a consequential experiment, record your version, and use platform-supported recovery steps rather than guessing at filenames.
