Yes: official Xbox information says *Beast of Reincarnation* is available with **Xbox Game Pass on day one**, August 4, 2026. The current Xbox facts tracked for this site identify **Xbox Game Pass Ultimate** and **PC Game Pass** as the relevant tiers. Steam and PlayStation are separate purchase surfaces; a Steam license is not a Game Pass entitlement.

## The short answer by platform

- **Xbox Series X|S:** official Xbox availability with Game Pass support.
- **Xbox on PC:** official Xbox information lists PC Game Pass availability.
- **Xbox Cloud Gaming:** the Xbox listing is tracked as cloud-enabled for the supported service and region.
- **Steam:** buy the PC version on Steam; Steam's own purchase and refund terms apply.
- **PlayStation 5:** use the PlayStation store listing; Game Pass does not transfer to PlayStation.

The [game info page](/game-info/) contains the broader platform and release facts. The official Xbox announcement is the source for the day-one subscription statement, while the Steam store is the source for Steam's own PC features.

## What Game Pass does not change

Game Pass access does not turn the game into a multiplayer title: Steam describes it as single-player, and the official game premise remains Emma and Koo's one-person, one-dog journey. Save, achievement, and cloud behavior can differ by platform service, so check the platform you are actually using instead of copying Steam instructions into an Xbox install.

For the PC version's own account features, see the [Steam features guide](/guides/steam-features-guide/).
