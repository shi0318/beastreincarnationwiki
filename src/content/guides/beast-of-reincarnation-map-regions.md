The released game is easier to navigate when you treat the map as a set of connected routes rather than a checklist of every collectible. The useful anchors are campsites, vertical traversal points, shrines, locked treasures and Cleanse Walker upgrade stops.

## Read the map by function

Every useful map note should answer one of four questions:

- Where is the next **campsite** or safe reset point?
- Which gap needs **Lift** or **Extend**?
- Which branch leads to a shrine, locked treasure or upgrade material?
- Is the route taking you toward a story objective or an optional sweep?

The [interactive map guide](/guides/interactive-map-guide/) is the broad index. The [campsite locations guide](/guides/campsite-locations/) and [wayside shrines guide](/guides/wayside-shrines-guide/) are better when the question is specifically about a return point.

## A reliable exploration order

Start by activating the closest campsite, then make one short sweep for a visible material or treasure. Only after the return route is comfortable should you cross into a new elevation band. This keeps a failed traversal attempt from costing the supplies needed for the next fight.

When a path appears to end at a broken bridge, look for the Extend anchor rather than assuming the area is unfinished. When a ledge is just above Emma's normal jump, check whether Lift has been unlocked. Some routes are designed to be revisited after traversal abilities improve.

## Map data that should stay versioned

The game supports optional exploration, but a complete coordinate database and a universal “100% map” route are not reproduced here. Patch notes can change collision, traversal or marker behaviour. Record the region, nearest campsite, ability requirement and build whenever you add a new marker.
