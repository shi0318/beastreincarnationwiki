The current Steam Community interactive-map guide links maps for **seven indexed zones**: Giant Tree Zone, Ogouchi Buffer Zone, Ancient Civilization Zone, The Great Wall Terraces, Pilgrim's Zone, Matsukawa Zone, and Fuji Frontier Zone. It is a player project hosted through Wand, not an official Game Freak map. Its value is the filter system: the guide lists Keeper Golems, valuables, crop seedlings, Wayside Shrines, Bulkheads, Control Panels, Field Bosses, campsites, and Locked Treasures.

## How to use the map without losing the plot

Start with one objective. For **Happy Camper**, enable Camp. For **Place of Return**, enable Wayside Shrine. For **Finders, Keepers**, enable Keeper Golem. For **Green Thumb**, use crop and seedling filters. Add Bulkheads and Control Panels only when a route is gated. This makes a screenshot or pin useful evidence instead of turning the screen into an unreadable wall of icons.

The [campsite guide](/guides/campsite-locations/) and [seedling guide](/guides/seedlings-crops-guide/) turn those filters into separate checklists. The map author's filters can change independently of the shipped game, so record the map update date and verify every pickup in your save.
